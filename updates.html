v0.3.12 2026-08-05 현재 버전

Windows 터미널 호환 수정 — 계정 연동·Storybook 미리보기

  • Windows 에서 claude 계정 연동 터미널이 "'&&' 토큰은 올바른 문 구분 기호가 아닙니다" 오류로 멈추던 문제를 수정했습니다 (기본 PowerShell 5.1 환경)
  • Storybook 미리보기가 "파일 이름, 디렉터리 이름 또는 볼륨 레이블 구분이 잘못되었습니다" 오류로 뜨지 않던 문제를 수정했습니다 (기본 cmd 환경)
  • 터미널 명령을 어떤 셸(PowerShell 5.1/7 · cmd · bash)에서도 동작하는 방식으로 전면 교체 — 같은 계열 오류의 재발을 차단했습니다
v0.3.11 2026-08-04

Windows 첫 설치 안정화 — 잔여 함정 5종 보강

  • 셋업 점검에 claude 계정 로그인 확인을 추가 — 미로그인으로 실행만 조용히 실패하던 첫 설치 흔한 원인을 잡고, 미로그인 시 로그인 터미널을 바로 열어줍니다
  • Figma 연동 등록이 낡은 주소로 남아 '이미 등록됨'으로 위장하던 경우를 감지해 자동 재등록합니다
  • 사용자 폴더 경로에 공백이 있는 환경(OneDrive 프로필 등)에서 실행이 실패하던 문제를 수정했습니다
  • 백신 검사로 첫 실행이 지연될 때 간헐적으로 '미설치'로 오판하던 것을 방지했습니다 (점검 대기 상향)
  • claude 실행 경로 설정이 잘못 남아 있는 경우 원인을 명시해 안내합니다
v0.3.10 2026-08-04

Windows 안정화 — claude CLI 인식 문제 근본 수정

  • Windows 에서 claude CLI 가 설치돼 있는데도 계속 '미설치' 로 안내되고, Figma → Code 연동이 멈추던 문제를 근본 수정했습니다
  • 설치 직후나 네이티브 설치본처럼 PATH 에 아직 안 잡힌 경우도 주요 설치 경로를 보강해 자동으로 찾습니다
  • 세션 도중 CLI 설치를 마치면 에디터 재시작 없이 바로 인식됩니다
  • 아주 긴 프롬프트가 Windows 명령줄 길이 제한에 걸리던 경로를 차단했습니다

v0.3.2 2026-08-05

Talk to Image 일러스트 다양성 개편 · 설정 화면

  • 일러스트가 매번 같은 구도(베이지 카드 + 상반신 인물)로 나오던 문제를 개편했습니다 — 주제에 따라 전신 인물·두 사람·사물 중심·작은 장면 등으로 구도가 달라지고, 배경 색도 8종에서 주제 분위기에 맞게 골라집니다
  • 인물 그림 품질 개선 — 목·어깨 비율 보정, 포즈 다양화, 실제 서비스 일러스트 레퍼런스 확충(전신·2인·장면)
  • 설정 화면 신설 — 계정 연동 관리와 Claude 사용량 확인 패널
  • Launchpad 프로젝트 상단에 커버리지 지표 — 전체/현재 화면 범위 필터, 지표별 문제 위치·해결 방법 안내와 해당 화면으로 바로 이동
v0.3.1 2026-08-04

Talk to Spec 대개편

  • PRD 문서 구조를 5개 섹션으로 개편 — 제품 정의(Overview) · 문제 정의와 솔루션 · 프로젝트 범위(Scope) · 기능 요구사항 요약 · 리스크와 향후 과제. 흐름이 섞이고 중복되던 서술을 정리했고, 기존 문서도 새 구조로 표시됩니다
  • AI 검토 개편 — 검토 패널이 PRD·기능명세 어느 단계에서든 열리고, 본문을 가리지 않는 사이드 패널로 나란히 비교하며 봅니다. 지적마다 자동 수정 외에 해당 위치로 이동하는 직접 수정을 지원하고, 수정안은 항목별로 골라 반영합니다
  • 재생성이 전체 덮어쓰기에서 항목별 머지로 — PRD·기능을 다시 생성하면 교체/추가/삭제될 항목을 미리 보고 골라서 반영합니다. 직접 수정한 내용은 기본으로 보존됩니다
  • 버전 이력 — 재생성 반영·AI 자동 수정 같은 큰 변경 직전 상태가 자동으로 보관되고, 언제든 그 시점으로 복원할 수 있습니다
  • User Flow 개선 — 기능명세 기반 생성 계약(빈 명세 차단·기능 배지), 흐름 구조 점검, PNG/SVG 내보내기, 선 교차를 줄인 직교 배선과 자동 정렬
  • 기획서 저장 안전망 — 저장 실패 시 자동 재시도와 브라우저 보관·복원 안내로 작성 내용이 유실되지 않습니다
