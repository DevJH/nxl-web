v0.7.0 2026-10-07 현재 버전

디자인 생성 품질 개편과
대규모 기획 지원

  • 디자인이 더 완성된 화면으로 나옵니다: AI가 화면 구성을 먼저 잡고 디자인시스템 부품을 입히는 방식으로 바뀌었습니다. Mono 대고객 화면은 시안 → 구성 명세 → 디자인시스템 세 단계로 만들고, 검수는 판단 근거를 보여 주며 오탐을 줄였습니다.
  • 한 프로젝트의 화면이 서로 맞습니다: 서비스명·헤더·메뉴·상태 라벨 색·버튼 위계를 프로젝트에서 한 번 정해 모든 화면이 같이 씁니다. 대표 화면을 기다리지 않고 처음부터 동시에 그려 일괄 디자인도 빨라졌습니다.
  • Mono 디자인시스템: 흰 바탕과 잉크 색을 기본으로 하는 색 규칙, 서비스 헤더·안내 글 부품과 커머스 패턴, 비회원 홈·가로 목록 스크롤·데스크톱 화면 구성 기준이 추가됐습니다. 관리자 화면은 회색 위주에서 벗어났습니다.
  • Hanwha 디자인시스템: Foundation 261001 토큰과 가이드라인 2.1.0을 반영하고 관리자(백오피스) 시스템을 분리했습니다. 동의서 상세·원본 참고·의미별 패턴과 배너 자산이 추가됐고, 화면을 먼저 구성한 뒤 디자인시스템으로 옮겨 그립니다.
  • 기본 디자인 시스템은 NXLDS: 새 프로젝트는 NXLDS로 시작하고, 추천은 Hanwha·Mono 브랜드 중에서 고릅니다.
  • 디자인 패널에서 더 많이 고칩니다: 차트 데이터를 항목 × 계열 표로 바로 고치고, 헤더 제목·입력 라벨처럼 부품 안의 글자를 따로 골라 고치거나 지울 수 있습니다. 직접 수정이 화면을 깨뜨리면 이전 화면을 유지한 채 알려 주고 이전 코드로 되돌릴 수 있습니다. Hanwha 화면의 요소 추가 목록은 그 디자인시스템의 부품을 보여 줍니다.
  • 기능이 많은 서비스도 기획합니다: 기능을 영역(메뉴·업무 단위)으로 묶고, 기능이 수십~수백 개면 개요를 먼저 만든 뒤 영역별로 상세를 채웁니다. User Flow도 영역마다 나눠 그려 하나로 합칩니다. 기능명세는 영역별 목차·표 보기·전체 개요·기능 창으로 새로 정리했습니다.
  • 요구사항 문서 가져오기: 양식대로 "미정"을 많이 적은 문서가 분석에 실패하던 문제를 고쳤습니다. 문서의 미정 항목은 기획 단계의 「확인할 것」으로 올라오고, 문서에 적은 예시 데이터가 화면에 그대로 쓰입니다.
  • 기획이 중간에 사라지지 않습니다: 기획 초안이 사소한 형식 결함이나 연결 끊김으로 통째로 버려지던 문제, 간선 하나 때문에 User Flow 전체가 버려지던 문제를 고쳤습니다. User Flow는 시스템 처리 순서도 대신 화면을 뼈대로 그립니다.
  • 작업 환경: 스킬 라이브러리가 추가되고, Talk to Image 화면(스타일 미리보기·모션 내보내기)과 디자인 편집기(레이어 검색·여러 요소 속성 함께 고치기)를 개편했습니다. 설정은 일반·AI 설정·사용량으로 합치고 추론 강도를 고를 수 있습니다. 도움말은 사용 순서·자주 묻는 질문·연결 진단으로 다시 구성했습니다.
v0.6.0 2026-09-17

프로젝트 이동과
프로토타입 안정성 개선

  • 프로젝트 내보내기·가져오기(.nxlproj): 기획·User Flow·디자인·대화·개발 워크스페이스를 파일 하나로 다른 컴퓨터에 옮깁니다. 같은 설치본에 가져오면 프로젝트 복제가 됩니다.
  • 프로토타입이 멈추지 않습니다: 흐름과 어긋난 시나리오만 빼고 사유를 보여 줍니다. 로그인 경로가 "이동할 수 없음"으로 잘못 막히던 문제를 고쳤고, 화면은 스텝마다 맨 위에서 시작합니다.
  • 개발 모드: 타입 오류만 남은 앱은 미리보기를 먼저 열어 주고 오류 목록과 AI 수정은 그대로 둡니다. 생성 워크스페이스의 typecheck 오류 대부분을 근본에서 줄였습니다(디자인시스템 정비).
  • 전역 알림: 진행 스트립·토스트·알림 센터·데스크톱 알림으로 AI 작업 완료를 어디서든 알 수 있습니다.
  • Mono 디자인시스템: 상태색·모서리·깊이까지 브랜드가 정하고, 소셜 로그인 버튼과 로그인 화면이 추가됐습니다. 부품(Carousel 등)은 Components/Mono 로 정리했습니다.
  • Hanwha 디자인시스템: Figma 2.1.0 실측으로 간격·Tabs·Segment·Card 를 교정하고, coreds UX 패턴 가이드라인 원문을 Patterns/Hanwha 에 실었습니다.
  • UI 정리: 알림·검토 도크 등의 왼쪽 색 막대 장식을 없앴습니다.

인스펙터 편집 개선 · 반응형 편집 · 하단 탭/고정 버튼 정본 · 진행 복원

  • 인스펙터에서 더 많이 다듬습니다: 색·간격을 디자인시스템 토큰 목록에서 고르고, 숫자 칸은 드래그로 밀거나 +8 같은 수식으로 조정할 수 있습니다. 속성 이름이 한글로 표시되고, 여백은 상하좌우 박스로 한눈에 봅니다
  • 태블릿·데스크톱 반응형 편집: 한 화면 안에서 폭에 따라 달라지는 부분만 따로 지정할 수 있습니다 — 폭마다 화면을 따로 만들지 않아도 됩니다
  • 화면 원형에 맞는 패턴만 실립니다: 만들려는 화면의 종류·사용자·셸을 보고 관련 업무 패턴과 허용 컴포넌트만 골라 생성 지침에 실어, 엉뚱한 컴포넌트 사용과 지침 과부하가 줄었습니다
  • 하단 탭 · 고정 버튼 정본(NXLDS 0.2.3): 하단 탭이 선택 상태를 채운 아이콘으로 표현하고, 화면 아래 고정 버튼은 자기 높이만큼 여백을 스스로 확보합니다 — 마지막 내용이 버튼에 잘리던 문제가 사라집니다
  • 프로젝트를 다시 열면 하던 자리로: 디자인·프로토타입까지 진행한 프로젝트를 다시 열어도 늘 User Flow 로 돌아가던 문제를 고쳤습니다. 이제 마지막으로 손댄 단계가 열립니다
  • 이어서 디자인할 때 정의서를 다시 만들지 않습니다: 화면을 잇거나 옮기기만 해도 전 화면 정의서를 재생성하던 문제를 고쳐, 일괄 디자인을 이어 하는 시간이 크게 줄었습니다
  • 연결이 끊긴 디자인 자동 복구: 플로우 노드에 붙지 못한 「기타 디자인」이 디자인 탭에 들어갈 때 자동으로 제자리에 다시 연결됩니다
  • 개발 모드: Figma 화면을 개발 모드로 바로 가져올 수 있고, 다른 컴퓨터에서 만든 개발 폴더가 없을 때는 다시 만들 자리를 안내합니다. 반출 시 문법이 깨진 화면 하나가 조립 전체를 세우던 문제도 해소됐습니다
  • 기획: 인수조건 자동 채우기와 PRD·기획안 검증이 보강됐습니다
  • Windows: 설치 위치가 다양한 claude CLI 를 더 넓게 찾습니다
