v0.3.9 2026-07-29 현재 버전

전사 배포 시작

  • 배포 채널(이 사이트)을 통한 설치 파일·사용자 메뉴얼 제공 시작
  • 사용량 집계에 제품 구분을 추가해 Builder · Studio 사용량을 분리 집계
v0.3.82026-07-27

기능별 사용량 집계 정합성 개선

기능별 사용 현황이 대시보드에서 정확히 묶이도록 집계 기준을 정비했습니다.

v0.3.72026-07-27

사용량 집계 전송 설정 수정

집계 이벤트가 수집 서버에 도달하지 않던 설정 문제를 바로잡았습니다.

v0.3.62026-07-27

사용량 집계 — 사번 기반 식별 도입

실행 1건당 집계 이벤트 1개만 전송하며, 프롬프트·코드·응답 본문은 전송하지 않습니다.

v0.3.52026-07-24

설치 파일(VSIX) 경량화

불필요한 의존성을 제거해 설치 파일 크기를 절반으로 줄였습니다.

v0.3.42026-07-24

실행 사용량 집계 1차 도입

v0.3.32026-07-24

MUI 미리보기 충실도 — 정본 테마 전체 반영

Figma → Code 미리보기가 실제 앱과 동일한 디자인시스템 테마 전체로 렌더됩니다.

v0.3.22026-07-16

프로젝트 커스텀 컴포넌트 인식

프로젝트가 DS 를 래핑해 만든 컴포넌트를 워크스페이스 매핑(.nextlab/rules/figma-mapping.md)과 Figma Code Connect 로 선언하면 Figma → Code 가 이를 반영합니다.

v0.3.02026-07-14

사내 배포 마일스톤 — 버전별 전달 패키지 체계

설치 안내·릴리스 노트·사용자 가이드·무결성 검증 파일을 갖춘 전달 패키지 체계를 도입했습니다.
