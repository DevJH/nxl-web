# Studio 화면 캡처

2026-09-22~23, `localhost:3200`의 실제 NEXTLAB Studio 화면을 촬영했습니다.
사이트의 제품 소개에는 빈 시작 화면 대신 결과물이 있는 프로젝트를 사용합니다.

| 파일 | 용도 | 실제 화면 |
| --- | --- | --- |
| `design-*.jpg` | 히어로 · Studio 대표 화면 | 새 작업 공간 518의 LIFEPLUS SELECT 멤버십 홈. 직접 제작·보정한 HTML 시안을 저장한 뒤 제목을 선택해 레이어와 속성을 함께 표시 |
| `spec-*.jpg` | Studio 기획 소개 | 새 프로젝트 559, 주말의 발견 전시 예약 예제의 기능명세·완료 조건 |
| `flow-*.jpg` | Studio User Flow 소개 | 새 프로젝트 559. 경험 탐색 → 전시 상세 → 방문 일정 → 예약 완료의 네 화면과 시작·완료 지점을 함께 표시 |
| `prototype-*.jpg` | Studio 프로토타입 소개 | 프로젝트 559의 직접 작성한 예약 시나리오. 체험 화면·행동 안내·전체 단계 목록을 함께 표시 |
| `dev-*.jpg` | Studio 개발 소개 | 프로젝트 559에서 실제 조립·실행한 개발 작업대. 프로젝트 파일, 라우팅 코드, 실제 빌드 검사 결과를 표시 |
| `plan-*.jpg` | 이전 촬영본 보관 | 프로젝트 시작 화면 |
| `tools-*.jpg` | 이전 촬영본 보관 | AI 도구 목록 |

상세 사용 가이드의 화면은 2026-09-23에 전부 다시 촬영한 [`images/studio-manual`](../studio-manual/README.md)을 사용합니다. 제품 소개용 캡처와 별도로 관리합니다.

제품 소개용 10장은 1680×1050 뷰포트, 기기 배율 2(이미지 3360×2100)로 촬영했습니다.
`light` / `dark`는 실제 앱의 테마입니다. 대표 디자인은 사용자의 요청에 따라 새로 제작했습니다. [원본과 제작 기록](../../examples/studio-membership/README.md)을 참고하세요. 기획·기능명세와 User Flow도 [가상 서비스 예제](../../examples/weekend-discovery/README.md)로 새로 만들었습니다. 기존 프로젝트는 수정하지 않았습니다.
이미지를 합성하거나 색상 필터를 적용하지 않았습니다. Builder 화면은 기존 저장소의 실제 작업 캡처를 사용합니다.

새 캡처를 추가할 때는 로딩 완료, 실제 산출물, 읽을 수 있는 배율, 두 테마를 모두 확인하세요.
교체 후 `node scripts/version-assets.mjs`를 실행해 이미지 주소의 내용 해시도 갱신하세요. 갤러리 탭과 확대 화면은 이 버전이 적용된 주소를 함께 사용합니다.
