# Studio 매뉴얼 캡처

2026-09-23, `localhost:3200`에서 실행 중인 실제 Studio를 촬영한 매뉴얼 전용 화면입니다. `studio-manual.html`은 기존 `launchpad`·`studio15` 캡처를 사용하지 않습니다.

이미지는 기기 배율 2의 JPEG입니다. 기본은 1680×1050 뷰포트의 3360×2100이며, `project-archive-*`는 메뉴를 더 크게 읽을 수 있도록 1680×650 뷰포트의 3360×1300으로 촬영했습니다. 각 화면을 앱의 실제 라이트·다크 테마로 촬영했습니다. 앱 UI를 이미지로 합성하거나 결과 메시지를 주입하지 않았습니다.

| 파일 | 촬영 내용 |
| --- | --- |
| `start-*` | 기획 시작 화면에 전시 예약 서비스 요구사항 입력. 전송하지 않은 입력 예시 |
| `settings-*` | 설정 → AI 모델. 계정 정보나 토큰을 표시하지 않는 공통 설정 화면 |
| `questions-*` | 프로젝트 576, 직접 작성해 저장한 전시 예약 서비스의 기획 질문 예제 |
| `prd-*` | 프로젝트 559의 제품 목표·출시 범위·대표 여정 |
| `spec-*` | 프로젝트 559의 예약 신청 기능과 완료 조건 |
| `flow-*` | 프로젝트 559, 흐름 `f-mudchn3n`의 네 화면과 연결선 |
| `screens-*` | 프로젝트 559의 디자인 화면 목록 |
| `design-*` | 연결된 디자인 560의 탐색 화면에서 제목을 선택한 속성 편집 상태 |
| `insert-*` | 같은 디자인에서 요소 추가 메뉴를 연 상태 |
| `prototype-*` | 프로젝트 559의 전시 예약 시나리오와 단계·피드백 패널 |
| `dev-*` | 프로젝트 559의 실제 파일 목록·라우팅 코드·기존 빌드 검사 결과 |
| `exports-*` | 프로젝트 559의 산출물 내려받기 메뉴와 항목별 준비 상태 |
| `tools-*` | 현재 AI 도구 목록 |
| `personal-tools-*` | 입문 안내용 전체 도구의 검색·분류·도구별 고정 버튼. 현재 실제 화면을 다시 촬영 |
| `project-archive-*` | 프로젝트 목록에서 ‘주말의 발견’으로 검색 후 프로젝트 559의 메뉴를 연 상태. 상단 가져오기와 내보내기(.nxlproj)를 함께 표시 |
| `writing-*` | 별도로 만든 `weekend-manual` 브랜드 기준과 예약 완료 안내 문구. 기존 기준은 변경하지 않음 |
| `image-*` | 새 이미지 작업 577에서 직접 제작한 전시 패스 SVG를 열어 선택한 상태 |
| `figma-*` | 전시 예약 예제 폴더와 package.json을 열고 컴포넌트 생성을 준비한 상태. Figma 링크를 제출하거나 변환을 실행하지 않음 |

질문, 기획, 디자인과 그래픽은 설명을 위한 직접 작성 예제입니다. AI가 생성했다는 결과나 실행 기록을 만들지 않았습니다. 실제 예약·결제·외부 Figma 변환 결과를 의미하지 않습니다.

현재 매뉴얼은 18개 장면, 총 36개 이미지를 사용합니다. 개인 홈과 시작 화면 설정은 현재 로컬 라우트에 연결되어 있지 않아 가짜 캡처를 만들지 않았습니다. 문서에는 현재 제공 상태와 해당 메뉴가 있는 설치 버전의 사용 순서를 구분했습니다.
