Studio 오류 대응표 전체 41개

기준 판 0.9.1 · 2026-11-03 작성. 옅은 면 글자는 화면에 그대로 나오는 문구입니다.
현장 해결 어려움 표시는 원문의 ‘준비된 PC로 옮김’ 항목입니다. 오늘은 PC 교체가 없으므로 화면 사진을 찍어 진행 담당에게 전달합니다.

검색 결과가 없습니다. 화면 사진과 문구를 진행 담당에게 전달해 주세요.

내려받기 · 설치 13개
1공통
설치 파일 내려받기가 오래 걸림설치 파일이 맥 약 450MB, Windows 약 380MB입니다. 여러 명이 현장 Wi-Fi로 함께 받으면 느려집니다.
미리 받아 오도록 안내합니다. 현장에서는 USB 등으로 설치 파일을 나눠 줍니다.
2Windows
브라우저가 내려받은 설치 파일을 막음 (Edge: 일반적으로 다운로드되지 않는 파일, Chrome: 안전하지 않을 수 있는 파일)서명 전 배포판이고 받는 사람이 적은 파일이라 브라우저가 경고합니다.
다운로드 목록에서 해당 파일의 … 메뉴 → 유지 → 그래도 유지를 누릅니다.
3공통
디스크 공간이 부족해 설치가 멈춤설치하면 앱이 약 1.0~1.2GB를 차지하고, 프로젝트를 만들면 더 늘어납니다.
2GB 이상 비우고 다시 설치합니다.
4맥
앱이 열리지 않음(이 Mac에서 지원되지 않는다는 안내) 또는 Rosetta를 설치하라는 창맥 종류와 다른 설치 파일을 받았습니다. Intel 맥에는 Apple 칩용이 열리지 않고, Apple 칩 맥에서 Intel용을 열면 Rosetta를 요구합니다.
애플 메뉴 → 이 Mac에 관하여에서 칩을 보고 맞는 파일을 다시 받습니다. Apple M…이면 Apple 칩용, Intel이면 Intel용입니다.
5맥
처음 열 때 인터넷에서 내려받은 앱인데 열겠느냐고 물음맥이 처음 여는 앱마다 묻는 정상 확인입니다.
열기를 누릅니다.
6맥
응용 프로그램 폴더로 끌어 넣을 때 같은 이름의 항목이 있다는 창, 또는 사용 중이라 바꿀 수 없다는 안내예전 판 Studio가 설치돼 있거나 켜져 있습니다.
예전 Studio를 종료(⌘Q)한 뒤 대치를 누릅니다. dmg 안에서 바로 실행하지 말고 꼭 응용 프로그램 폴더로 옮긴 뒤 엽니다.
7Windows
Windows의 PC 보호 창이 뜸배포판이 아직 Windows 게시자 서명 전이라 나오는 안내입니다.
추가 정보 → 실행을 누릅니다.
8Windows현장 해결 어려움
스마트 앱 컨트롤이 앱을 막았다는 알림 (실행 버튼 없음)Windows 11의 스마트 앱 컨트롤이 켜져 있으면 서명 전 앱을 예외 없이 막습니다.
넘길 방법이 없습니다. 다시 켜기 어려운 설정이라 끄라고 하지 말고 준비된 PC로 옮깁니다.확인: Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정
9Windows
설치 중 Studio가 실행 중이라 계속할 수 없다는 안내예전 판 Studio가 아직 켜져 있습니다.
작업 관리자에서 NextLab Studio를 끝내고 설치를 다시 진행합니다.
10Windows
설치할 때 관리자 권한을 요구함설치 대상으로 모든 사용자를 골랐습니다.
설치 대상을 현재 사용자 전용으로 바꿔 다시 설치합니다. 관리자 권한이 필요 없습니다.
11Windows현장 해결 어려움
이 앱은 이 PC에서 실행할 수 없다는 안내Studio는 64비트(x64) Windows 10 이상용입니다. 32비트 Windows나 Windows 10 ARM에서는 실행되지 않습니다.
준비된 PC로 옮깁니다.
12공통현장 해결 어려움
회사 보안 프로그램이 설치나 실행을 막았다는 알림회사 PC 보안 정책입니다.
현장에서 풀 수 없습니다. 준비된 PC로 옮깁니다.
13공통
업데이트 있음 · 새 버전 … 이 있습니다. 창예전 판을 설치해 둔 사람입니다. Windows는 받은 뒤 지금 재시작을 누르면 진행 중인 생성이 끊깁니다.
시연 중에는 나중에를 누릅니다. 시작 전이라면 최신 판을 새로 설치하고 시작합니다.
첫 실행 · Claude 로그인 16개
14공통
Claude로 로그인을 눌렀는데 브라우저가 안 열림기본 브라우저가 앞으로 나오지 않았거나 열기에 실패했습니다.
Studio 창 아래 로그인 브라우저 다시 열기를 누릅니다.
15공통
로그인 브라우저 탭이 두 개 열림같은 로그인 창이 두 번 열린 것입니다.
한 탭에서만 로그인하고 다른 탭은 닫습니다.
16공통
연결은 됐는데 계정 칸의 이메일이 본인 것이 아님브라우저에 다른 Claude 계정이 로그인돼 있어 그 계정으로 연결됐습니다.
계정 칸의 로그아웃으로 끊고, 브라우저에서 claude.ai 계정을 바꾼 뒤 Claude로 로그인을 다시 누릅니다.
17공통현장 해결 어려움
브라우저에 Claude Code에 연결하려면 Claude Max, Ultra 또는 Pro가 필요합니다무료 계정으로 로그인했습니다.
브라우저에서 Pro · Max · Ultra 구독 계정으로 바꿔 로그인한 뒤 Claude로 로그인을 다시 누릅니다. 구독 계정이 없으면 준비된 PC로 옮깁니다.
18공통
코드를 붙여 넣었는데 확인 중…에서 넘어가지 않음코드 일부만 복사됐습니다. 코드는 # 뒤까지가 한 덩어리입니다.
  1. 브라우저의 복사 버튼으로 코드 전체를 다시 복사해 붙여 넣습니다.
  2. 그래도 그대로면 취소 후 Claude로 로그인을 다시 누릅니다.
19공통
claude auth login 이 코드 1 로 종료됐습니다.코드가 받아들여지지 않았습니다. 시간이 지났거나, 이미 쓴 코드거나, 이전 로그인 창의 코드입니다.
예전 탭을 닫고 Claude로 로그인을 다시 눌러 새로 열린 창의 코드로 진행합니다.
20공통
로그인이 5분 안에 끝나지 않아 취소했습니다.브라우저 로그인을 5분 넘게 마치지 않았습니다.
Claude로 로그인을 다시 누릅니다.
21공통
이미 연결 중입니다. 완료하거나 취소한 뒤 다시 시도해주세요.앞서 누른 연결이 아직 진행 중입니다.
취소를 누른 뒤 다시 연결합니다.
22공통
설치 파일 응답이 올바르지 않습니다. 회사 네트워크의 접속 제한을 확인해주세요. 또는 응답 시간이 초과됐습니다. 네트워크를 확인하고 다시 시도해주세요.회사망이 Claude 배포 주소를 막고 있습니다.
현장 Wi-Fi나 휴대폰 핫스팟으로 바꾸고 다시 누릅니다.
23공통
브라우저 로그인은 됐는데 코드 확인 뒤 실패함회사 프록시입니다. 브라우저는 PC의 프록시 설정을 따르지만 Studio 안의 Claude 연결은 따르지 않습니다. 회사 Windows PC에서 자주 생깁니다.
현장 Wi-Fi나 핫스팟으로 바꾸고 Claude로 로그인부터 다시 합니다.
24공통현장 해결 어려움
앱에 든 Claude 를 실행할 수 없어 공식 Claude Code 를 설치합니다…이 PC에서 앱에 든 Claude가 돌지 않습니다. 맥은 macOS 12(Monterey) 이하, Windows는 Pentium · Celeron 저가형이나 Snapdragon(ARM) Surface에서 나옵니다.
로그인까지 될 수는 있지만 화면 생성은 보장할 수 없습니다. 준비된 PC로 옮깁니다.확인: 맥은 애플 메뉴 → 이 Mac에 관하여(macOS 13 Ventura 이상이어야 함), Windows는 설정 → 시스템 → 정보 → 프로세서
25공통
계정 칸에 이메일 없이 계정 연결됨만 보임이 PC의 터미널 Claude Code가 회사 게이트웨이 · Bedrock 등 다른 연결로 설정돼 있습니다. 이대로 시작하면 디자인 단계에서 인증 실패로 멈춥니다. 정상 연결은 이메일 · MAX처럼 이메일과 요금제가 함께 보입니다.
  1. Studio를 완전히 종료합니다.
  2. 설정 파일 이름을 잠시 바꿉니다.
    맥: mv ~/.claude/settings.json ~/.claude/settings.json.bak
    Windows: %USERPROFILE%\.claude\settings.json 이름 변경
  3. Studio를 다시 켜고 Claude로 로그인.
  4. 시연이 끝나면 파일 이름을 되돌립니다.
Windows는 같은 설정이 환경 변수로 걸려 있을 수 있습니다. PowerShell에서 Get-ChildItem Env: | Where-Object Name -Match 'ANTHROPIC|CLAUDE_CODE_USE'에 결과가 나오면 시스템 속성 → 환경 변수에서 잠시 지워야 하므로, 본인이 원하지 않으면 준비된 PC로 옮깁니다.
26공통현장 해결 어려움

개인 구독 계정으로 다시 로그인합니다. 회사 계정만 있으면 준비된 PC로 옮깁니다.

자주 받을 질문
이미 쓰는 Claude Code와 버전이 달라도 되나요?

됩니다. Studio는 앱에 든 Claude를 쓰고, 로그인 정보는 버전과 상관없이 같은 자리에 저장돼 함께 씁니다. 2.1.202부터 2.1.314까지 같은 로그인을 그대로 읽는 것을 확인했습니다.

Studio에서 로그아웃하면 어떻게 되나요?

로그인을 함께 쓰므로 터미널 Claude Code도 같이 로그아웃됩니다. 시연이 끝난 뒤 따로 로그아웃할 필요는 없습니다.

Pro 계정으로도 되나요?

됩니다. 화면 4장 기준으로 기획부터 프로토타입까지 한 번 돌리면 5시간 한도의 절반 아래를 씁니다.
