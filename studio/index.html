첫 실행 안내 — 임시 절차입니다

아직 OS 인증서 서명이 적용되지 않아 첫 실행을 한 번 막습니다. 정식 서명이 적용되면 사라질 절차이며, 최초 1회만 하면 됩니다.

macOS: "악성 코드가 없음을 확인할 수 없습니다" 창 → 닫고 시스템 설정 → 개인정보 보호 및 보안 아래쪽 "그래도 열기" → 다시 실행

Windows: SmartScreen 파란 창 → 추가 정보 → 실행

기존 데이터를 옮기려면 앱에서 파일 > 데이터 가져오기… 를 사용하세요.
