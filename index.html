설치 방법

  1. VSCode 확장 패널 우측 상단 메뉴에서 Install from VSIX 로 내려받은 파일을 설치합니다.
  2. 에디터를 완전히 재시작합니다 (Cmd+Q 후 다시 실행).
  3. Cmd+Shift+A 로 패널을 열고, 상단 연동 배지를 눌러 Claude / CodeX 계정을 연동합니다.

Figma 변환은 최초 1회 환경 셋업이 추가로 필요합니다 — 설치 후 명령 팔레트에서 NEXTLAB Builder: Figma → Code 환경 셋업 을 실행하세요.
